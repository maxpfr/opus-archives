Installer dans Gmail
  1. Sélectionne la signature ci-dessous (du nom jusqu'à l'adresse postale) et copie-la (Ctrl/Cmd + C).
  2. Gmail → ⚙️ → Voir tous les paramètres → Général → Signature → Créer.
  3. Colle dans l'éditeur (Ctrl/Cmd + V), puis dans « Valeurs par défaut des signatures », associe-la à maxime@opus-archives.com.
  4. Enregistre les modifications en bas de page.
